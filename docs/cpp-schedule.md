# C++ 学习课表

> **目标**：为游戏/图形开发打基础 · **起点**：有编程概念，C++ 零基础
> **节奏**：每周 2 次，每次 1~2 小时 · **周期**：2026-10-19 起

**总原则**：只规定顺序，不规定哪天完成。落后就整体后移，不补课。

> 本文件只回答一个问题：**学什么、按什么顺序、怎样算学会。**
> 进度看 [progress.md](progress.md)｜教学规矩看 [teaching-notes.md](teaching-notes.md)

## 课表

| 课次 | 主题 | 验收标准 |
|---|---|---|
| 1 | 程序结构、编译流程 | 不看资料写出并跑通一个输出 3 行的程序 |
| 2 | 变量、类型、cin/cout | 写出「输入两个数、输出和」，编译零警告 |
| 3 | if / else / bool 逻辑 | 输入血量，正确输出「存活 / 濒死 / 死亡」三个分支 |
| 4 | 循环 for / while | 打印 1~10 的偶数；能说清循环变量为什么不用 int |
| 5 | 函数：参数与返回值 | 拆出 `attack()` 返回伤害；用引用参数改血量 |
| 6 | std::vector | 用 vector 存 5 个怪物名并遍历打印；说清 `size()` 返回 `std::size_t` 而非 `int` |
| 7 | std::string | 写「名字长度 + 首字母 + 拼接」的小程序 |
| 8 | struct 组织数据 | 定义 `Player{hp, atk}`，写 `apply_damage(Player&, int)` |
| 9 | 引用 vs 指针 | 说出 3 条区别，并各写一个正确例子 |
| **9.5** | **switch + enum 小专题**（半小时） | 用 `enum class` 定义动作，`switch` 分发，未知动作有 default 分支 |
| 10 | 栈 / 堆 / unique_ptr | 解释为什么不用 new/delete，改用 `std::make_unique` |
| 11 | 类：封装、const、初始化列表 | 把 Player struct 改成 class，hp 私有 + getter；写出带初始化列表的构造函数；说出 const 变量 / const 成员函数各限制什么 |
| 12 | 析构、拷贝、运算符重载 | 构造/析构各打印一行，观察顺序；写拷贝构造并证明复制出的是两个独立对象；让 `cout << player` 能打印 |
| 13 | 继承 + 虚函数 | 基类 Enemy + 派生 Boss，用基类指针得到不同行为 |
| 14 | 模板 + lambda | 写 `template<typename T> max_of`；用 lambda 按 hp 排序 |
| **14.5** | **map 与 unordered_map** | 用 map 统计词频；说清两者在“有序”和“查找速度”上的取舍 |
| 15 | 多文件工程 | 拆成 `main.cpp / player.h / player.cpp` 并编译通过 |
| 16 | 移动语义、拷贝控制 | 说清 `std::move` 前后对象各处于什么状态；解释 Rule of Three 为什么成立 |
| 17 | 结课项目：practice08 升级版 | 多文件拆分 + class 封装 + Enemy 继承 + map 背包 + 玩家自主选动作，≥200 行 |
| 18 | static、std::array、异常 | 各写一个最小例子：静态成员计数、定长数组、`try/catch` 捕获 `throw` |
| 19 | 未定义行为与防御性编程 | 列出 4 种 UB，各写一个能触发的最小例子，并说出正确写法 |

**顺带讲**（不单独占课次）：

| 挂在 | 内容 |
|---|---|
| 第 11 课 | `auto`、range-for（`for (const auto &x : v)`） |
| 第 15 课 | `namespace`、`#pragma once` / 头文件保护 |
| 第 16 课 | `std::optional`、`std::string_view`（现代 C++ 的"可能没有"与"不拷贝子串"） |
| 第 18 课 | `fstream` 文件读写、`enum` 底层类型 |
| 第 19 课 | `assert`、不变量、防御性检查 |

**编号说明**：9.5 与 14.5 是插入的半小时专题；19 是结课项目之后的安全补课。**编号不重排**，避免打乱已有练习文件名。

**未列入课表、需要时单独加**：`CMake`、调试器（gdb / VS Code 断点）。这两项属于工程能力，不属于 C++ 语法。

**里程碑**：第 8 课 → 能模拟打怪 3 回合；**第 17 课** → 能独立做出多文件小游戏

**第 13 课讲法**：先用已有素材制造需求——`Player`（30 血）和 `Enemy`（200 血）想放进同一个 `vector` 遍历，但 Boss 受伤减半，`vector<Player>` 做不到 → 引出「同一个指针，不同的行为」，再讲虚函数。

**第 15 课之后**：花 2 小时**只看不做** UE 项目结构（新建 C++ 项目 → 翻一眼生成的 `.h`/`.cpp` → 确认"也就是 class + 继承 + 宏"→ 关掉）。目的是建立坐标系，不是学引擎。

## 不在范围内

- ❌ C 风格数组、`printf`、头文件里的 `using namespace std;`
- ❌ **用裸 `new`/`delete` 写代码**（第 10 课会讲它们**为什么危险**，但那只是为了理解 `unique_ptr` 为什么必要；实际代码一律用 `std::make_unique`）
- ⏳ SFML / UE 放在 16 课之后

## 每次课流程

| 阶段 | 时长 | 内容 |
|---|---|---|
| 讲解 | 20~30 分钟 | 一个概念 + 最小可运行例子 |
| 演示 | 10 分钟 | 故意写错的代码，看真实报错 |
| **你写** | 40~60 分钟 | 练习 `practiceNN.cpp`，你敲，我不代劳 |
| 批改 | 15 分钟 | 指出错误属于哪类问题 |
