# 从这里开始

> 开新对话时，复制下方分隔线内的全部内容发给助手。

---

我在学 C++，资料都在 `cpp-learning` 文件夹。请按顺序读：

1. `cpp-learning\docs\progress.md` — **学到哪了、我的易错点**
2. `cpp-learning\docs\cpp-schedule.md` — **学什么、什么顺序**
3. `cpp-learning\docs\teaching-notes.md` — **怎么教、环境问题**
4. `cpp-learning\docs\assignments.md` — **当前作业要做什么、长什么样**

代码（`.cpp`）在 `cpp-learning\` 根目录，教学文档都在 `cpp-learning\docs\`。

读完告诉我你理解到的进度，然后按 `progress.md` 的「待办」继续。

要求：

- **不要从第一课重来**，从 progress.md 的下一课开始
- 遵守 teaching-notes.md 的 9 条规则，尤其是规则 1（分三层：作业里只许写已教过的，讲解可借用但要标记）、规则 3（示例先跑通）、规则 8（作业单格式）、规则 9（讲解风格）
- 每节课开头给我**四色工具表**（✅已掌握 / 🟢本节新教 / 🔵借用 / ⚪只提一句）
- 讲到 `progress.md`「易错点」里的内容时，主动提醒我
- 先讲道理再给命令，我自己操作
- 我追问"为什么"时讲透，别敷衍

## 五个文件各管什么

| 文件 | 只回答 | 什么时候更新 |
|---|---|---|
| `START-HERE.md` | 这份启动指令本身 | 文件位置或阅读顺序变化时 |
| `progress.md` | 学到哪了、有什么、错在哪 | 每课后说"更新进度" |
| `cpp-schedule.md` | 学什么、什么顺序、怎样算学会 | 课程调整时 |
| `teaching-notes.md` | 怎么教、环境怎么配 | 出现新教训时 |
| `assignments.md` | 每次作业的具体要求 | 布置新作业时 |

**一个字都不重复。** 需要新信息时，先判断它属于哪个文件。
