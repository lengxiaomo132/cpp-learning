# 一、character.h — 基类

**所有角色（玩家、敌人）共有的东西。**

## 私有 / 保护成员

| 成员 | 类型 | 说明 |
|---|---|---|
| `name` | `std::string` | 名字 |
| `hp` | `int` | **当前**血量 |
| `max_hp` | `int` | **最大**血量（构造时设定，之后不变） |
| `atk` | `int` | 攻击力 |

**访问权限用 `protected`**——派生类（`Player`、`Enemy`）要能访问它们。

## 函数清单

### `Character(std::string n, int h, int a)`

**做什么**：构造函数。设置名字、当前血量、最大血量、攻击力。

**要点**
- 用**初始化列表**
- `max_hp` 和 `hp` **都设成 `h`**（初始满血）
- **`atk` 必须赋值为 `a`**——不赋值就是未定义行为

### `virtual ~Character() = default;`

**做什么**：虚析构。

**要点**：一行，写在 `.h` 里。`= default` 表示用编译器默认实现。

### `std::string get_name() const`

**返回**：`name`

### `int get_hp() const`

**返回**：`hp`（当前血量）

### `int get_max_hp() const`

**返回**：`max_hp`（最大血量）

### `int get_atk() const`

**返回**：`atk`

### `bool is_alive() const`

**返回**：`hp > 0`

### `void take_damage(int dmg)`

**做什么**：扣血，**但不允许扣成负数**。

**逻辑**
```
hp = hp - dmg
如果 hp < 0
    hp = 0
```

**要点**
- **不要**在这里再减 `defense()`——减伤由调用方（battle）算好再传进来
- 写进 `character.cpp`

### `virtual int defense() const`

**返回**：`0`

**要点**：基类没有防御，返回 0。派生类会改写它（Boss 有护甲、玩家防御时减伤）。

### `virtual std::string type_name() const`

**返回**：`"角色"`

**要点**：派生类各自改写。

### `operator<<`

```cpp
std::ostream &operator<<(std::ostream &os, const Character &c);
```

**做什么**：打印角色信息。

**输出格式**
```
名字(hp=当前/最大)
```

**例子**：`Orc(hp=40/40)`

**要点**
- **写在类外面**（成员函数做不到 `cout << c` 这个形式）
- 用参数 `os`，**不要写死 `std::cout`**
- 最后 `return os;`（不写能编译，但会崩）
- `character.h` 需要 `#include <ostream>`

**可选**：想加 `[Boss]` 标记可以在派生类里覆盖 `operator<<`，或让 `operator<<` 调用 `type_name()`。

# 二、player.h — 玩家

**继承自 `Character`。**

## 私有 / 保护成员

| 成员 | 类型 | 说明 |
|---|---|---|
| `bag_` | `std::map<std::string, int>` | 背包：物品名 → 数量 |
| `defending_` | `bool` | 本回合是否处于防御状态 |

**需要 `#include <map>`**

## 函数清单

### `Player(std::string n, int h)`

**做什么**：构造函数。

**要点**
- **必须先调用基类构造**：`Character(n, h, 15)`（玩家攻击力固定 15）
- `defending_` 初始化成 `false`
- **初始物品不知道放哪吗？** 可以在这里加 `bag_["药水"] = 3; bag_["炸弹"] = 1;`，也可以留给 `main` 调用 `add_item`。**二选一，由你决定。**

### `void add_item(const std::string &item, int count)`

**做什么**：往背包里加物品。

**逻辑**
```
bag_[item] += count        ← 累加，不是赋值
```

**要点**
- 用 `+=`，不是 `=`（已有物品要累加，不是覆盖）
- 这里可以用 `[]`——因为这个函数**不是** `const` 的，允许修改

### `bool use_item(const std::string &item)`

**做什么**：用掉一个物品。成功返回 `true`，没有就返回 `false`。

**逻辑**
```
用 find 找 item
如果没找到 或 数量 <= 0
    返回 false
数量 - 1
返回 true
```

**要点**
- **用 `find`，不要用 `[]`**——`[]` 找不到时会插入
- 数量减到 0 后，物品**仍然留在 map 里**（数量为 0），不需要 erase

### `int item_count(const std::string &item) const`

**做什么**：查询某个物品有多少个。

**逻辑**
```
用 find 找 item
如果没找到，返回 0
返回 it->second
```

**要点**
- 这是 `const` 函数，**绝对不能用 `bag_[item]`**——会插入，违反 `const`，编译失败

### `void set_defending(bool d)`

**做什么**：设置防御状态。

**逻辑**：`defending_ = d;`

### `int defense() const override`

**做什么**：改写基类的 `defense()`。

**返回**
```
defending_ 为 true  →  5
否则             →  0
```

**要点**：必须写 `override`；函数末尾必须 `const`（基类是 `const`）。

### `void print_bag() const`

**做什么**：打印背包内容。

**输出格式**
```
背包：药水 x3  炸弹 x1
```

**要点**
- 用 range-for + 结构化绑定：`for (const auto &[k, v] : bag_)`
- 背包为空时打印 `背包：（空）`

# 四、battle.h — 战斗流程

## 动作枚举

```cpp
enum class Action { Attack, Defend, Item, Flee, Unknown };
```

**要点**：用 `enum class`（不是 `enum`），避免名字污染。

## 私有成员

| 成员 | 类型 | 说明 |
|---|---|---|
| `player_` | `Player &` | 引用玩家（战斗要改玩家的血和背包） |
| `enemies_` | `std::vector<std::unique_ptr<Enemy>>` | 敌人列表 |
| `round_` | `int` | 当前回合数 |

**需要 `#include <memory>`、`#include <vector>`、`#include "player.h"`、`#include "enemy.h"`**

## 函数清单

### `Battle(Player &p)`

**做什么**：存玩家引用，回合数归零。

**要点**：`: player_(p), round_(0) { }`

### `void add_enemy(std::unique_ptr<Enemy> e)`

**做什么**：把敌人加进列表。

**逻辑**
```
enemies_.push_back(std::move(e));
```

**要点**
- **必须 `std::move`**——`unique_ptr` 不能复制（第 17 课）
- 不加 `std::move` 会编译失败

### `bool all_dead() const`

**做什么**：判断是否所有敌人都已死亡。

**逻辑**
```
遍历 enemies_
    如果有一个 is_alive() 为 true
        返回 false
返回 true
```

**要点**：空列表也返回 `true`（没有敌人 = 全死了）。

### `bool run_round(std::istream &in, std::ostream &out)`

**做什么**：**核心函数**。执行一个完整回合。

**返回值**：
- `true` → 战斗继续
- `false` → 战斗结束（玩家死 / 敌人全灭 / 逃跑）

**完整流程**

```
① round_++
② out 打印 "\n=== 第 N 回合 ===\n"
③ 打印所有活着的敌人
④ 打印玩家状态（血量）
⑤ 打印动作菜单，读入选择
⑥ 把选择转成 Action
⑦ switch 分发，执行动作
⑧ 如果玩家死了，直接 return false
⑨ 所有活着的敌人反击
⑩ player_.set_defending(false)      ← 回合结束清掉防御
⑪ return player_.is_alive() && !all_dead()
```

### 各动作的具体行为

**Attack（攻击）**
```
① 打印活着的敌人列表（带编号 1、2、3...）
② 读入目标编号
③ 检查编号是否合法、目标是否活着
④ dmg = player_.get_atk() - 目标->defense()
⑤ 如果 dmg < 1，dmg = 1
⑥ 目标->take_damage(dmg)
⑦ 打印："Hero 攻击 Orc，造成 15 伤害！Orc 剩余 25 血。"
```

**Defend（防御）**
```
player_.set_defending(true)
打印："Hero 进入防御姿态，本回合减伤 5。"
```

**Item（用药水）**
```
如果 player_.use_item("药水") 为 true
    回血 30（不超过 max_hp）
    打印剩余血量
否则
    打印"没有药水了"
```

**回血写法提示**：`Character` 没有 `heal` 函数。可以用 `take_damage(-30)`（负伤害 = 加血），但**这很别扭且容易出错**。

**建议**：在 `Character` 里加一个 `void heal(int amount)`，逻辑是：
```
hp = hp + amount
如果 hp > max_hp
    hp = max_hp
```
**这是对 `character.h` 的一个补充需求。**

**Flee（逃跑）**
```
打印"你逃跑了..."
return false        ← 立即结束
```

**Unknown（无效）**
```
打印"无效动作"
```

### 敌人反击

```
遍历 enemies_
    如果 !is_alive()，跳过
    back = 敌人 get_atk() - player_.defense()
    如果 back < 1，back = 1
    player_.take_damage(back)
    打印："Orc 反击 Hero，造成 8 伤害！"
```

### 输入处理的要点

**读数字后必须检查 `in.fail()`：**

```
in >> choice;
if (in.fail())
{
    in.clear();
    in.ignore(1000, '\n');
    out << "请输入数字\n";
    return true;        ← 本回合跳过，不算崩
}
```

**⚠️ `clear()` 和 `ignore()` 两个都要——否则后面所有输入都失效（第 3 课、第 14.5 课的坑）。**

# 五、main.cpp — 主流程

## 完整流程

```
① 打印标题
   ==============================
           RPG 战斗演示
   ==============================

② 读玩家名字
   out << "请输入你的名字："
   std::cin >> name;

③ 读血量（1-200）
   out << "请输入血量（1-200）："
   std::cin >> hp;
   if (std::cin.fail() || hp < 1 || hp > 200)
   {
       提示错误，return 1;
   }

④ 创建 Player
   Player hero{name, hp};

⑤ 加初始物品
   hero.add_item("药水", 3);
   hero.add_item("炸弹", 1);

⑥ 打印角色信息
   out << hero.get_name() << "  HP " << hero.get_hp() << "/" << hero.get_max_hp()
       << "  ATK " << hero.get_atk() << '\n';
   hero.print_bag();

⑦ 创建战斗、添加敌人
   Battle battle{hero};
   battle.add_enemy(std::make_unique<Enemy>("Orc", 40, 8));
   battle.add_enemy(std::make_unique<Elite>("EliteGoblin", 30, 10));
   battle.add_enemy(std::make_unique<Boss>("Dragon", 200, 20, 5));

⑧ 战斗主循环
   while (battle.run_round(std::cin, std::cout))
   {
       // 空循环体：回合结束条件由 run_round 返回 false 决定
   }

⑨ 打印结果
   如果 hero.is_alive() 且 battle.all_dead()
       打印 "胜利！"
   否则如果 !hero.is_alive()
       打印 "你倒下了..."
   否则
       打印 "你逃跑了。"
```

## 战斗循环的说明

**`while (battle.run_round(std::cin, std::cout))` 这一行的含义：**

- **每调用一次 `run_round`，就打完一个完整回合**
- **返回 `true` → 战斗继续，再打一回合**
- **返回 `false` → 战斗结束，退出循环**
- **循环体是空的**——所有工作都在 `run_round` 里面完成了

**这就是「把回合变成一个函数调用」的设计——`main` 不需要知道回合内部怎么运作。**

## 结束判断的三个分支

| 条件 | 输出 |
|---|---|
| `hero.is_alive() && battle.all_dead()` | `胜利！` |
| `!hero.is_alive()` | `你倒下了...` |
| 其他（玩家活着但敌人没死光） | `你逃跑了。` |

# 九、对现有 `character.h` 的修改点

**你的现状：**

```cpp
Character(std::string n, int h) : name(n), hp(h) {}    // 缺 atk！
std::string get_name() const { return name; }
int get_hp() const { return hp; }
int get_atk() const { return atk; }
```

**需要改：**

| 问题 | 改法 |
|---|---|
| **构造函数缺 `atk` 参数** | 改成 `Character(std::string n, int h, int a)` |
| **`atk` 没初始化** | 初始化列表加 `atk(a)` |
| **没有 `max_hp`** | 加成员，初始化列表加 `max_hp(h)` |
| 缺 `max_hp` 的 getter | 加 `int get_max_hp() const;` |
| 缺 `is_alive` | 加 `bool is_alive() const;` |
| 缺 `take_damage` | 加 `void take_damage(int dmg);` |
| 缺 `heal` | 加 `void heal(int amount);` |
| 缺虚析构 | 加 `virtual ~Character() = default;` |
| 缺 `defense` / `type_name` | 加两个虚函数 |
| 缺 `operator<<` | 类外加声明 |
| **缺 `#include <ostream>`** | 顶部加（`std::ostream` 需要它） |
